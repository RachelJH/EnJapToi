# 현재 후원 효과 규칙

`feature/observe-payamount`, 2026-11-02. 이 문서가 이전 리뷰·README 변경 기록의 효과/가격/명령어 설명보다 우선합니다.

| 치즈 | 효과 |
|---|---|
| 1,000 | 버프, 안전 랜덤 이동, 빵 5개, 잔여 내구도 1 다이아몬드 곡괭이 각각 25% |
| 2,000 | 디버프 6종 중 하나, 30초 |
| 3,000 | 현재 X/Z의 안전한 지표면 이동 |
| 4,000 | 15% 사망, 85% 생존. 생존도 정상 완료 및 후원 알림 대상 |
| 5,000 | 비어 있지 않은 슬롯 하나의 전체 스택 삭제. 갑옷·보조 손 포함 |
| 30,000 | 확정 사망 |

버프는 신속·힘·재생·저항·점프 강화·성급함 중 하나를 60초간 부여합니다. 디버프는 구속·나약함·채굴 피로·실명·허기·멀미 중 하나입니다. 모두 레벨 I입니다. 메시지 내용으로 효과를 선택할 수 없으며 `!몹`을 포함한 이전 명령어도 일반 문자열로 취급합니다. 몬스터 소환 코드는 제거했습니다. 운영자 `/ejt test <event>`는 유지하지만 `mob`는 실패로 종료됩니다.

랜덤 이동은 같은 월드의 로드된 청크에서 수평 반경 50블록 이내의 안전 지점을 찾습니다. 지표면 이동은 현재 소수점 X/Z를 보존하고 오버월드 최상단을 검사합니다. 위험한 지점, 안전 지점 없음, 다른 차원, 이동 취소는 기존 정책대로 실패합니다. 빈 인벤토리 삭제, 취소된 사망·포션, 일부 아이템 지급 실패에는 성공 알림이 없습니다.

## 대기열 호환성

기존 이벤트의 ID·효과·치즈 등급을 재추첨하거나 일괄 변경·삭제하지 않습니다. 과거 5,000치즈 `surface`/`chancekill`은 그대로 실행하고 기존 금액으로 알립니다. 과거 `mob`는 실행 함수를 호출하지 않고 알림 없이 종료합니다. Paper의 `DONE`은 처리 종료만 뜻하며 성공 판정은 false입니다. 실패한 효과에도 사용하던 기존 상태 의미를 유지합니다. Python의 이전 모의 outbox는 몬스터 항목을 `retired`로 보존하며 `done`으로 집계하지 않습니다. 관찰 모드에서는 이전 outbox도 소비하지 않습니다.

SQLite FIFO, 같은 ID 중복 방지, 오프라인·사망·리스폰 대기, 기본 `interval-ticks: 60`(3초), 실행 불확실 상태 보류, 완료 저장 이후 후원자 알림을 유지합니다. 실패를 자동 재실행하지 않으며 월드와 SQLite 사이의 원자성 한계도 유지됩니다.

## 관찰 모드와 검증

`payAmount`는 원화 문자열입니다. 치즈 환산을 가정하지 않습니다. `receiver.enable-game-delivery: false`를 유지하고 실제 금액 매핑·검증 파일은 생성·변경하지 않습니다. `tests/fixtures`는 가상 데이터 전용이며 운영 매핑의 근거가 아닙니다.

Python: `python -m unittest discover -s tests`에서 83개 중 81개 통과, 2개 건너뜀(Engine.IO 및 선택 Socket.IO 통합 의존성 미설치). Windows DPAPI 접근 때문에 전체 테스트는 사용자 권한에서 실행했습니다.

Java: Microsoft OpenJDK 25.0.5.0.2 / Apache Maven 3.9.16에서 `paper-plugin`의 `mvn -B clean package` 빌드가 성공했습니다. Java 테스트 49개가 모두 통과했으며 실패·오류·건너뜀은 0개입니다. 확률 경계·생존 완료 알림·기존 몬스터 종료/재시작·새 등급 HTTP 검증을 포함합니다.

실제 플레이어가 접속한 Paper 서버에서의 효과 실행과 실제 CHZZK 후원 연동은 아직 검증하지 않았습니다. 자동 테스트 통과는 실제 원화/치즈 대응 검증을 뜻하지 않습니다.

배포 시 서버 정상 종료 및 DB 백업 후 새로 빌드·검증한 JAR와 `bridge/bridge.py`, `bridge/receiver.py`를 함께 교체합니다. OAuth·비밀정보·기존 DB는 유지하고 게임 전달을 켜지 않습니다.
